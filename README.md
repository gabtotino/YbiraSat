# 🌳 YbiraSat

> Nossa Floresta Vista do Espaço

A YbiraSat é uma plataforma de inteligência ambiental preventiva desenvolvida para auxiliar na prevenção de queimadas através da visualização de dados ambientais, monitoramento geográfico e análise de riscos.

O projeto foi criado com o propósito de aproximar as pessoas da realidade ambiental brasileira e demonstrar como a tecnologia pode contribuir para a preservação das nossas florestas.

---

## 📌 Sobre o Projeto

As queimadas são uma das principais ameaças aos biomas brasileiros, causando impactos ambientais, sociais e econômicos.

Embora existam sistemas de monitoramento, muitas soluções atuam apenas quando o problema já aconteceu.

A YbiraSat busca mudar essa lógica, oferecendo uma plataforma que centraliza informações ambientais e auxilia na identificação de áreas com potencial risco, promovendo uma atuação mais preventiva.
